# 🌙 FAZO Restorani Namangan - Full-Stack Web Platform

Haqiqiy Namangan Milliy va Turk Oshxonasi Restorani Veb Platformasi.

## 🚀 Texnologiyalar Steki

- **Frontend**: React (Vite), Bootstrap 5, Lucide React, Custom CSS (Glassmorphism & Gold Theme)
- **Backend**: Node.js, Express.js, Mongoose ODM
- **Database**: MongoDB Atlas Cluster (Cloud Database)
- **Valyuta**: O'zbek So'm (`so'm`)
- **Til**: 100% Sof O'zbek Tili

---

## 📌 Asosiy Imkoniyatlar

1. **MongoDB Atlas Integratsiyasi**: Barcha taomlar, kategoriyalar, oshpazlar, sharhlar, buyurtmalar va foydalanuvchilar MongoDB Atlas bulutli ma'lumotlar bazasidan keladi.
2. **Advanced UI/UX Dizayn**: Yorqin va issiq oltin tusli shisha (glassmorphism) dizayn, 3D float va animatsiyalar.
3. **Savatcha va Buyurtma Rasmiylashtirish**: Yetkazib berish manzili va to'lov usullari bilan tezkor buyurtma berish.
4. **Admin Portal**: Taomlar va buyurtmalarni boshqarish uchun maxsus portal (`/admin`).
5. **100% Halol va Mobil Interfeys**: Mobil va planshet qurilmalar uchun to'liq moslashtirilgan.

---

## 🛠️ O'rnatish va Ishga Tushirish

### 1. Backend Serverni Ishga Tushirish (Port 5001)

```bash
cd backend
npm install
npm run seed  # MongoDB Atlas ma'lumotlarini yuklash
npm start
```

### 2. Frontend Dev Serverni Ishga Tushirish (Port 3000)

```bash
cd frontend
npm install
npm run dev
```

Brauzeringizda **http://localhost:3000** manziliga kiring.
